# Operation GO 🚀 (Lovable-Ready Edition)

Operation GO is a modern youth workforce development and contractor hiring portal based in Rochester, NY. Founded by Rochester City School District graduate Justin Ortiz, the initiative equips students with hands-on tool mastery, OSHA credentials, and direct union apprenticeship placement.

This project is tailored specifically for **[Lovable.dev](https://lovable.dev)** with a clean **React 18 + TypeScript + Vite + Tailwind CSS + GSAP Motion System** architecture.

---

## 🏗️ Tech Stack

- **Framework**: [React 18](https://react.dev/) + [Vite 5](https://vitejs.dev/)
- **Language**: [TypeScript](https://www.typescriptlang.org/)
- **Styling**: [Tailwind CSS 3](https://tailwindcss.com/) + Custom Foundry Design Tokens (Light & Dark theme)
- **Routing**: [React Router DOM v6](https://reactrouter.com/)
- **Icons**: [Lucide React](https://lucide.dev/)
- **Animations**: [GSAP 3](https://greensock.com/gsap/) with `@gsap/react` and `ScrollTrigger`

---

## 📱 Pages & Architecture

- `/` — **Home**: Split hero, live video scrim, enrolling cohort progress hub, core curriculum pillars, metrics, and CTA.
- `/about` — **About**: Justin Ortiz founder story, mission, core operating principles, and history.
- `/programs` — **Programs**: Detailed breakdown of 4 core vocational tracks (Carpentry, Electrical, HVAC, OSHA-10).
- `/impact` — **Impact**: Outcomes, starting apprentice wages ($22.50/hr avg), and graduate stories.
- `/careers` — **Careers**: Master contractor & instructor job board ($45-$65/hr) with direct application form.
- `/get-involved` — **Get Involved**: Employer partnerships, tool donation, and volunteer mentor avenues.
- `/support-us` — **Support Us**: 501(c)(3) tax-deductible sponsorship tiers.
- `/contact` — **Contact**: Rochester headquarters info and inquiry transmission form.
